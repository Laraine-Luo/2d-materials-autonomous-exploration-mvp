# MVP方法依据与初赛文稿映射

## 1. 160条合成材料记录来自哪里

它们不是Materials Project、C2DB或任何论文的数据，也不对应真实材料。它们由`src/materials_mvp/data.py`中的确定性生成器产生，仅用于验证软件接口、预算约束、反馈闭环、日志与基线比较是否能运行。

固定随机种子为2026。每条记录先从预设范围采样5个抽象数值特征：

- 平均原子序数：均匀分布 \(U(18,72)\)；
- 平均电负性：\(U(1.35,2.65)\)；
- 平均原子半径：\(U(0.95,1.75)\)；
- 层厚：\(U(2.6,7.8)\)；
- 对称性指标：\(U(0.05,1.0)\)。

Formation Energy由人为构造的关系生成：

\[
E_f=-0.72+0.006(Z-40)+0.16(r-1.3)+\epsilon_f,
\quad \epsilon_f\sim\mathcal{N}(0,0.14^2).
\]

Band Gap由人为构造的非线性关系生成：

\[
E_g=2.35-0.018Z+0.72(\chi-1.8)-0.12(t-4.5)+0.30s
+0.35\sin(Z/8)+\delta_p+\epsilon_g,
\]

其中 \(Z\) 为平均原子序数、\(\chi\) 为平均电负性、\(t\) 为层厚、\(s\) 为对称性指标；\(\delta_p\) 是演示用结构原型偏置（1H为+0.22，1T为−0.18，其余为0）；\(\epsilon_g\sim\mathcal{N}(0,0.18^2)\)。最后将Band Gap截断至0—4.5 eV。

这些公式没有材料物理上的拟合或文献依据，不能用于科学结论。选择160条只是为了让候选池大于初始样本与三组20次查询预算，同时保持演示快速；它不是科学上确定的数据规模。正式验证必须换成具有来源、计算设置与许可说明的真实二维材料数据。

为测试三稳定性字段接口，合成Energy Above Hull采用以下简单关系猜想：

\[
E_{hull}=\max(0,0.18+0.28E_f+\epsilon_h),\quad
\epsilon_h\sim\mathcal N(0,0.035^2),
\]

并令`is_stable = true`当且仅当 \(E_{hull}\le0.02\) eV/atom。该关系只用于最小闭环路径演示，不是依据真实Materials Project数据拟合的曲线，也不应出现在科学结论中。

## 2. 预测器的基础数学模型

### 2.1 岭回归

对标准化特征 \(x\) 建立线性预测：

\[
\hat y=\beta_0+x^T\beta.
\]

参数通过带L2正则的最小二乘得到：

\[
\hat\beta=\arg\min_\beta\left(\|y-X\beta\|_2^2+\lambda\|\beta\|_2^2\right),
\]

默认 \(\lambda=0.1\)，截距不惩罚。代码使用高斯消元求解正规方程。该模型是可解释、低依赖的MVP预测器，不代表最终最佳模型。

### 2.2 Bootstrap不确定性

从当前已知样本中有放回抽样，训练 \(B=12\) 个岭回归模型。对候选 \(x\)，预测均值和不确定性分别为：

\[
\bar y(x)=\frac{1}{B}\sum_{b=1}^{B}\hat y_b(x),
\]

\[
u(x)=\sqrt{\frac{1}{B-1}\sum_{b=1}^{B}(\hat y_b(x)-\bar y(x))^2}.
\]

这里的 \(u(x)\) 只是模型间离散度代理，尚未做概率校准。

## 3. 三种探索策略的基本规则

三种策略先应用同一组合稳定性规则。Formation Energy为主条件：

\[
\mathcal C_{stable}=\{x\mid E_f(x)\le -0.2\ \land\ (E_{hull}(x)\le0.1\ \lor\ is\_stable(x))\}.
\]

目标Band Gap区间暂设为 \([L,H]=[1.5,2.5]\) eV。定义目标接近度：

\[
T(\hat y)=
\begin{cases}
1, & L\le \hat y\le H,\\
\frac{1}{1+\min(|\hat y-L|,|\hat y-H|)}, & \text{其他。}
\end{cases}
\]

### 3.1 Random

从尚未查询的稳定候选集中均匀随机抽取：

\[
x_{next}\sim Uniform(\mathcal C_{stable}\setminus\mathcal C_{queried}).
\]

它是随机运气参照。

### 3.2 Static Top-N

只使用初始12个标签训练一次模型，随后冻结模型参数。每轮选择目标接近度最高的剩余候选：

\[
x_{next}=\arg\max_x T(\bar y_0(x)).
\]

查询反馈不会用于重训。它代表“静态预测—排序—筛选”的无迭代参照。当前实现逐轮从冻结排名中取剩余最高者，等价于静态Top-N顺序查询。

### 3.3 Iterative

每次查询后将真实Band Gap加入已知训练集并重新训练Bootstrap岭回归。令候选不确定性按当前池内最大值归一化，采集函数为：

\[
A(x)=(1-w)T(\bar y(x))+w\frac{u(x)}{\max_{x'}u(x')},
\]

默认 \(w=0.35\)。下一候选为：

\[
x_{next}=\arg\max_x A(x).
\]

这是一种“目标利用+不确定性探索”的简化主动搜索策略。它不是标准Expected Improvement或Upper Confidence Bound，正式报告必须按上述实际公式命名，不能误称为尚未实现的算法。

### 3.4 二维性审计规则

- `confirmed_2d`：允许进入训练集和候选池；
- `uncertain_2d`：写入审计日志，等待人工复核，确认前禁止训练和查询；
- `non_2d`：禁止训练和查询，同样保留排除记录；
- 统计/绘图：不确定与非二维记录以独立类别及相对已确认二维均值的偏离值呈现，不能静默丢弃，也不能混入模型性能指标。

## 4. 与已冻结第一部分的关联

| 第一部分已确认表述 | MVP中的具体落实 | 当前证据边界 |
|---|---|---|
| 大规模候选空间中的高效探索 | 固定候选池和有限查询预算 | 合成池只验证接口，不证明真实规模效果 |
| 目标电子性质与稳定性约束 | Band Gap目标区间 + Formation Energy硬筛选 | 阈值仍需真实数据和文献依据 |
| 预测—选择—反馈—再探索 | Iterative策略每轮预测、查询、重训 | 已有逐轮日志证明闭环运行 |
| 预测结果、不确定性与历史记录 | 岭回归均值、Bootstrap离散度、累计已知样本 | 不确定性尚未校准 |
| 有限计算资源 | 每查询一个隐藏标签消耗1/20预算 | 当前oracle是数据库标签，不是真实DFT计时 |
| 比较不同搜索策略有效性 | Random、Static Top-N、Iterative统一比较 | 单种子不足以判定优越性 |
| 探索应用边界 | 记录未胜过随机的结果及模型风险 | 需要真实数据、多种子和反例分析 |

第一部分的研究问题保持不变；MVP用于把其中的抽象概念转化为第2—4部分可检查的环境规则和验证证据。

## 6. “运行结果说明”是必备输出

从第1次运行开始，每次试跑都必须在README或最终PDF中至少说明：

1. 本次运行使用了什么数据、配置、预算和策略；
2. 得到了哪些量化结果；
3. 结果能够支持什么判断；
4. 结果不能支持什么判断；
5. 暴露了什么失败、风险或问题修正；
6. 下一轮因此改变什么。

第1次运行的规范说明：三种策略均完成20次查询且无稳定性违规，证明环境约束、查询预算、闭环和日志可运行。Iterative的MAE为0.273 eV，低于Random的0.358 eV和Static Top-N的0.388 eV；但Iterative目标命中率为70%，与Random相同。因此该单次合成数据运行不能证明迭代策略具有更高材料发现效率，只能作为可运行性证据，并提示需要真实数据、多随机种子、置信区间以及更有区分度的目标定义。
