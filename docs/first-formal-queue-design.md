# 首个正式队列：Materials Project MoS2结构多型微型闭环

## 选择

首个正式队列采用Materials Project公式层`MoS2`下的结构多型记录，网页交叉核验为12条，以MP ID作为候选主键。它不是最终科学训练集，而是第一份真实MP数据的“映射—审计—隐藏反馈—更新”闭环展示队列。

## 为什么符合四项要求

1. **轻量**：12条记录，初始4条、查询预算4、批量1，能够快速复现；
2. **闭环**：每轮预测、按策略选择一个MP ID、揭示数据库Band Gap、检查三稳定性信号、更新并记录；
3. **代表性**：同一公式存在多个结构多型，网页表中同时出现接近零与较高Energy Above Hull、零与非零Band Gap，能展示身份映射、稳定性约束和失败候选；
4. **可呈现**：MoS2容易被评委理解，`mp-1434`已有详情页证据，索引路径和一轮日志适合放入PDF/README。

## 有意保留的限制

12条不足以训练或比较可泛化的材料发现策略。因此这一队列只证明真实MP接口、规则和闭环可运行，不能支持“Iterative优于基线”或发现二维材料规律。完成后应扩展为同一MP版本、同一方法队列下更大的confirmed-2D候选池。
