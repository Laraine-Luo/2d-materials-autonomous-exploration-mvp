# 第7次运行：发现信号深化与真实表格导出演练

## 3.1深化结果

新增`docs/discovery-signal-spec-3.1.md`，把“发现”分为D0技术事件、D1数值命中、D2审计后候选、D3可复现研究信号和D4外部验证发现。MVP最多主张D2—D3；Materials Project已有记录对Agent未知，不等于对科学界未知。

正向候选要求Material ID/具体结构、确认二维、Formation Energy主条件、Hull/`is_stable`辅助条件、Band Gap目标、无标签泄漏及完整来源同时成立。另行预注册规律、异常、反例、稳定负结果和问题修正信号。

策略成功初步门槛：真实固定候选池、至少20种子下，Iterative平均D2发现数同时超过Random和Static Top-N至少10%，成对差异95%置信区间不含0。否则报告未超过参照。

## 文献/数据库约束

Materials Project说明常用DFT系统性低估Band Gap，内部测试在修正后仍有约0.6 eV残余MAE，0 eV还可能涉及解析或任务变化。因此数据库目标区间命中只能称为“Materials Project计算口径下的候选命中”。C2DB与二维材料综述还表明，二维稳定性包含热力学、动力学和弹性等层面，本项目三字段规则仍是MVP代理。

## 表格导出演练

在MoS2的12条结果页打开Export Table，勾选Include Structures并两次执行Confirm Export。应用内浏览器均未收到下载事件，页面也未给出明确导出错误。没有伪造成功文件。

该结果说明：网页适合人工核查，但导出行为在当前受控浏览器中不可稳定复现；后续正式数据获取应使用官方API。第6次运行人工核查的12条表格值和mp-1434详情证据仍有效，但不替代API数据文件。
