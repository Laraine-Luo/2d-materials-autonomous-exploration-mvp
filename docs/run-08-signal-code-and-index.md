## 2. 对原有设计的落实与调整

落实了“发现必须预先定义、异常需要人工审核、日志可审计”的设计。调整点是把`target_hit`与`discovery`彻底分开：命中目标Band Gap仅为D1，通过二维性、三项稳定性接口与来源审计后才是D2。单次MVP运行不能成为D3。

MoS2被明确记录为化学式/组成层；真正的候选身份采用MP ID。这避免同一公式的不同结构多型被错误合并。
