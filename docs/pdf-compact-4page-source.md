## 第1页：问题与证据

采用`docs/pdf-part1-frozen.md`中的标题及1.1—1.3原文，不改变核心表述。页面底部增加一条证据链：Materials Project/C2DB数据积累 → 静态性质预测 → 缺少统一探索、预算、日志和发现评价 → 本项目自主探索环境。

## 第2页：环境接口

正式数据仅来自Materials Project；160条随机记录只验证软件。候选主键为MP ID，MoS2索引为`Materials Explorer → Mo-S → MoS2 → mp-id`。一次运行冻结数据库版本、计算方法队列、候选池、目标区间、初始样本、预算和随机种子。目标Band Gap为1.5—2.5 eV；稳定性规则为`Formation Energy≤-0.2`且`Energy Above Hull≤0.1或is_stable`。阈值是MVP评价规则，不等于可合成判据。

Agent观察候选、预测值、不确定性、稳定性、审核状态、历史和预算；行动是选择下一MP ID；环境返回MP计算性质、误差、信号和预算消耗。Random为均匀抽样，Static Top-N冻结初始模型，Iterative按“目标接近度＋归一化不确定性”选择并在反馈后重训。日志记录轮次、身份、预测、反馈、选择理由、稳定性、D0—D2、审核与预算。首队列为12条MoS2索引，其中7条通过正式稳定性门槛；有效运行采用3条初始标签＋3次查询＋1条未揭示候选。

## 第3页：发现信号与参照

D0为技术／索引事件；D1为数据库Band Gap数值命中；D2为命中并通过MP身份、二维性、稳定性、计算方法及质量审核；D3为在留出数据和重复运行中复现；D4为更高精度计算、独立数据、文献或实验验证。单条查询最高自动判D2。预测误差大于`max(0.6 eV, 2u)`标记异常并人工审核。

基线为Random、Static Top-N和Iterative，使用相同数据、初始样本、预算与评价函数。比较D2数、首次D2预算、命中率、MAE、违规和异常。160条测试数据的一次运行结果为：Random 11/20、MAE 0.413；Static 14/20、0.398；Iterative 12/20、0.322；均无稳定性违规。它只证明闭环可运行，不能证明Iterative更优。

技术成功要求一键运行、预算终止、日志完整、种子可复现；真实微型闭环要求至少8条审核合格记录。策略成功要求至少20个共同种子下，Iterative平均D2同时高于两个基线至少10%，且成对差异95%置信区间不含0。未达门槛、版本/方法混合、数据泄漏或结果由离群点驱动均报告失败。

## 第4页：最小验证、风险与开源

试跑：固定版本MP查询12个MoS2 MP ID → 保存本地原始响应与脱敏审计 → 字段映射 → 证据护照 → 二维性与`origins → task_id → thermo run_type`方法审核 → 对7条稳定合格记录执行3＋3＋1三策略闭环 → 输出日志、信号和参照结果。三策略均为2/3个D2，Iterative未超过基线。

当前真实试跑在DNS解析阶段失败；官方客户端也无法下载。系统停止映射和训练，返回记录0、护照更新0、训练合格0，未用网页或合成数据替代。这验证了数据源隔离和失败阻断。

主要风险：API失败、数据库漂移、计算方法混合、非二维记录、Band Gap代理误差、标签泄漏、小样本偶然性、无证据人工/LLM批准。处理方式分别为失败审计、版本冻结、方法联查、人工二维性审核、异常标记、隐藏标签检查、多种子置信区间和签字留痕。

开源代码、配置、映射、索引、护照、基线、日志与测试；密钥、账号、原始本地响应和虚拟环境不上传。Materials Project数据记录版本、查询与CC BY 4.0许可。进入复赛后提供一键入口、多种子日志和可替换策略接口。
