# 第 28 次运行：文档模型身份表示修正

## 1. 本次完成了什么

- 显式队列请求成功，数据库版本和所有性质字段齐全。
- 发现原始探针在关闭 `use_document_model` 与 Monty 解码时保存了字母内部编码，而官方默认文档模型与 ID 解析方法均返回数值 MP ID。
- 将正式探针改回官方默认文档模型，使用模型自身的 JSON 序列化。
- 新增硬性身份闸门：返回 ID 集合必须与冻结的 12 个请求 ID 完全相同，否则 API 阶段失败且不映射。

## 2. 对原有设计的落实与调整

- 继续以 MP ID 为候选主键，公式仅作分组条件。
- 不把客户端内部编码登记成新的材料身份，也不建立未经官方模型支持的别名。
- 修正此前“候选空间漂移”的暂定解释：当前证据更支持客户端表示层差异。
- 只有修正后的探针重跑通过，才允许更新证据护照。

## 3. 对应初赛文稿哪些部分

- §2.1：固定文档模型、数据库版本和候选 ID 集合。
- §2.2：API 反馈增加实体身份一致性检查。

- §3.3：身份集合不完全一致即失败。

1. 使用修正后的默认文档模型重跑 12 条正式队列。
