# Materials Project manual probe — provenance evidence, not training data

This directory is separate from `data/test_fixture/`. It records a small human-readable website exercise against Materials Project database version `v2026.04.13`.

The rows are manually transcribed from the Materials Explorer detail page for schema/provenance validation. They are **not yet eligible for model training** because the reproducible API download, field mapping, and versioned dimensionality review pipeline have not been completed.
