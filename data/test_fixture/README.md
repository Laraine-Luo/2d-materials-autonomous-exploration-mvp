# Random synthetic test fixture — not research data

Everything in this directory is test-only. It must never be described as Materials Project data, a scientific dataset, or a materials-discovery result.

`random_synthetic_materials.csv` contains 160 deterministic but randomly generated demonstration records. The number of rows, feature ranges and label relationships have no empirical or literature basis. It mirrors only the minimum software schema expected from a future Materials Project export:

- `material_id`, `formula`, `prototype`: identity and grouping fields;
- `atomic_number_mean`, `electronegativity_mean`, `atomic_radius_mean`, `layer_thickness`, `symmetry_index`: numeric model features;
- `formation_energy_ev_atom`: primary stability metadata;
- `energy_above_hull_ev_atom`, `is_stable`: auxiliary synthetic stability checks;
- `dimensionality_status`: `confirmed_2d`, `uncertain_2d`, or `non_2d`; uncertain records are audited but excluded from training;
- `band_gap_ev`: oracle label hidden from the policy until a query spends budget.

Run `python scripts/generate_sample_data.py` to reproduce it exactly. Production/real Materials Project downloads must be stored outside this directory.

For this synthetic fixture only, energy above hull is generated by the unsupported guess `max(0, 0.18 + 0.28 * formation_energy + Gaussian noise)`, and `is_stable` is true at ≤0.02 eV/atom. These relations have no scientific basis and exist solely to test a three-signal stability interface.
