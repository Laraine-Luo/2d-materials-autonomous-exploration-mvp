# Data directories

- `test_fixture/`: 160 random synthetic records used only for software and closed-loop testing.
- `materials_project_manual_probe/`: small real website observations used only for field/provenance rehearsal; not training data.
- Future real Materials Project data must use a separate provenance-labeled directory and must not overwrite or be mixed with the test fixture.

The repository currently does not contain a verified Materials Project 2D training dataset.
